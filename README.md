# PolyCup
<img width="1110" height="325" alt="image" src="https://github.com/user-attachments/assets/da9c5fbf-0539-4397-9d44-9a9f6bfd4558" />

PolyCup 0.6.1 browser client, based on PolyTrack 0.6.3 and PolyModLoader.

```sh
npm ci
npm run prepare:game
npm run build
```

Requires Node.js 24. Output: `output/standalone/site-pml/`. Running online features requires a compatible PolyCup backend; private hosting tools are not included.

PolyCup application code: GPL-3.0-or-later. See [LICENSE.md](LICENSE.md) and [NOTICE.md](NOTICE.md). PolyTrack game files are fetched locally and are not included in this repository.
